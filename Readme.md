# Ollama AI Chatbot

A simple conversational AI chatbot built using Python and Ollama with the Llama 3.2 model.

## Features

* Interactive command-line chatbot
* Uses Ollama for local AI responses
* Maintains conversation history
* Supports exit and stop commands

## Technologies Used

* Python
* Ollama
* Llama 3.2

## Installation

Install the Ollama Python package:

```bash
pip install ollama
```

Make sure Ollama is installed and the `llama3.2` model is available.

## Run the Project

Run the following command:

```bash
python conv.py
```

Then enter your messages in the terminal.

To end the conversation, type:

```text
exit
```

or

```text
stop
```

## Example

```text
🤖 Ollama AI Chatbot
Type 'exit' or 'stop' to end the conversation.

You: Hello
AI: Hello! How can I help you today?

You: What is Python?
AI: Python is a popular programming language...
```
